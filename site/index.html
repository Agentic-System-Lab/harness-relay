Your CLIs, not imitations

Harness Relay never calls a model API. It starts the claude, codex and grok you already have, with their own tools, sessions and logins, passes each agent the messages it hasn’t seen yet, and streams everything into one chat.

You don’t need all three. Any subset works, and you sign in to each one from Settings.

Choose how they take turns

Each conversation has its own rules: who speaks, in what order, and when it ends. Address anyone with an @mention and only they reply.

Roundtable

Agents speak in order, and each sees what earlier speakers said. Set one to five rounds; the run ends early when everyone in a round replies [PASS].

Good for discussions, reviews and refining an answer.

Parallel

Everyone answers at the same time, on their own. Later rounds see the earlier answers. With edit access each agent works in its own git worktree, and you apply the result you like.

Good for comparing approaches and getting independent opinions.

Relay

One agent at a time. An agent hands the floor to a teammate by @mentioning them; if it mentions nobody, the floor returns to you. You set the maximum number of hand-offs.

Good for pipelines: plan, implement, review.

Design the team, or let the lead agent do it

Design it yourself. Give each agent a position (architect, builder, reviewer, skeptic), pick its model and reasoning effort, and set the speaking order. Up to eight members, several on the same CLI if you like. Roles can change mid-chat.

Or use Auto team. Describe what you need. The lead agent reads it with every template in full, then uses one as it is, adapts one, or designs a new team, and says why. You confirm before anyone answers, and can keep its team as a template.

Runs on your machine

Nothing is hosted. The server listens on your computer only, and agent replies cannot make your browser load remote content.

  • Bound to 127.0.0.1; cross-site requests are rejected.
  • Git snapshots for every turn that edits; parallel agents in their own worktrees.
  • API keys in your OS credential store: macOS Keychain, Windows Credential Manager or Secret Service.
  • Your conversations live in one SQLite file.
File permission, set per conversation
Read-only Reading, searching and looking things up on the web.
Edit Also editing files in the working directory and running project commands such as tests and builds. Pushing and publishing are not included.
Full access Everything, without asking. Use it only in directories you trust.

Edit doesn’t sandbox project code: tests and scripts run code the agents can change. For code or instructions you don’t trust, use read-only.

Quick start

  1. Install what it drives

    • Node.js 22.13 or newer
    • Any of the CLIs: Claude Code (claude), Codex CLI (codex), Grok CLI (grok)

  2. Clone and start

    $ git clone https://github.com/Agentic-System-Lab/harness-relay
$ cd harness-relay
$ npm install
$ npm run dev

  3. Sign in, then chat

    Open http://localhost:5173. Under Settings & sign-in, check that each agent is signed in. Then New chat: choose Auto team, design your own, or pick a template.

One process instead: npm run build && npm start serves everything on http://127.0.0.1:8787.
