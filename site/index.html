The coding agents you already have, working together

One kind of agent is enough for a team: all of one kind, or any mix of Claude Code, Codex, Grok, Cursor Agent, Antigravity, GitHub Copilot CLI, Muse Code and five open-source coding agents on your own model backends. For each question, the lead agent designs the team with each model’s own traits in mind: each member’s role and model, and how they take turns. Once you confirm it, the real agents on your machine work on your code, or any question, and answer each other.

The agents you installed, as they are

Harness Relay never calls a model API. It starts the claude, codex, grok, cursor-agent, agy, copilot and muse you already have, with their own tools, sessions and logins, passes each agent the messages it hasn’t seen yet, and streams everything into one conversation. OpenCode, Goose, Cline, OpenHands and Pi are started the same way, on the model backends you set up.

Open-source agents, on your own model

OpenCode, Goose, Cline, OpenHands and Pi join a team like the other seven. They run on the model backends you set up in Settings: an API key for OpenAI, Anthropic or xAI, or your own OpenAI-compatible endpoint, such as vLLM, Ollama, LM Studio or llama.cpp.

openhands acp, the Agent Client Protocol.

pi --mode rpc, JSONL RPC; below full access, a gate extension asks before each tool call.

Below full access, each of them, with everything it starts, runs in Harness Relay’s own OS sandbox. It writes only its own temp folder and its own sessions, which no other conversation’s agent can read or change, and in edit mode the working directory and the conversation’s attachments too. It reaches the run’s model backend without asking; other hosts are asked about, except this computer’s own addresses, a few the agent contacts by itself and any past the 30th in a run, which are refused. Approvals come as the same cards in the conversation.

Your keys, or your own endpoint

Give a member its model as backend/model: openai/gpt-5.4-nano, or your endpoint’s id and a model name, such as homelab/muse-glimmer-30b-nvfp4. Keys go to your OS credential store, and each run gets only its own backend’s key.

These agents take API keys only: the Claude subscription and Grok’s sign-in cannot be used by them. Claude Code and Grok themselves keep using their own sign-ins.

Choose how they take turns

Each conversation has its own rules: who speaks, in what order, and when it ends. Address anyone with an @mention and only they reply.

Roundtable

Agents speak in order, and each sees what earlier speakers said. Set one to five rounds; the run ends early when everyone in a round replies [PASS].

Good for discussions, reviews and refining an answer.

Parallel

Everyone answers at the same time, on their own. Later rounds see the earlier answers. With edit access each agent works in its own git worktree, and you apply the result you like.

Good for comparing approaches and getting independent opinions.

Relay

One agent at a time. An agent hands the floor to a teammate by @mentioning them; if it mentions nobody, the floor returns to you. You set the maximum number of hand-offs.

Good for pipelines: plan, implement, review.

A team for every question

The lead agent picks it. For each new question, it reads the question, the conversation so far, the current team and every template in full. Then it keeps the team, uses a template as it is, adapts one, or designs a new team, and says why. You confirm before the team answers, or let it answer right away.

It writes each role for its model. Claude, GPT, Gemini, Grok, Meta's Muse, Cursor's Composer and open-weight models each take instructions their own way, as their makers' own guides say. The lead agent writes each member's role the way that member's model takes it best, and reads only the guides for the models your agents run.

You design the templates. Give each agent a position (architect, builder, reviewer, skeptic), pick its model and reasoning effort, and set the speaking order. Up to eight members, several of them the same agent if you like. A team the lead agent designed can be kept as a template in one click.

  • Share a conversation as a linkShare the whole conversation, or everything up to one reply, as a page that looks like the conversation on screen, without tool calls and thinking. Runs on your machine

Harness Relay hosts nothing. The server listens on your computer only (when you try it in GitHub Codespaces, on your own codespace, at an address only your GitHub account can open), and agent replies cannot make your browser load remote content.

  • Bound to 127.0.0.1 and takes only browsers you signed in; cross-site requests are rejected.
  • Below full access, Claude Code’s, Codex’s, Grok’s, Copilot and Muse Code’s commands run in their own OS sandbox: they write only in the working directory, and can’t read your browsers’ folders or Harness Relay’s data. Cursor has no sandbox, so it asks you before every command (or refuses it, if the conversation refuses automatically), except those on your Cursor team’s allowlist. Antigravity has none either: it asks you before every command, and a refusal ends its turn. A refusal ends Copilot’s turn too.
  • The five open-source agents, and everything they start, run in Harness Relay’s own sandbox (sandbox-runtime: Seatbelt on macOS, bubblewrap on Linux, a filtering proxy for the network): the same folders are out of reach, each member’s sessions are its own, and only the run’s model backend is reachable without asking. If it can’t start, they don’t run; on native Windows they run only with full access.
  • Git snapshots for every turn that edits; parallel agents in their own worktrees.
  • API keys and MCP server tokens in your OS credential store: macOS Keychain, Windows Credential Manager or Secret Service; where there is none, as in a codespace, encrypted in the database.
  • Your conversations live in one SQLite file; Harness Relay publishes one only when you share it as a link.
File permission, set per conversation
Read-only Reading, searching and looking things up on the web.
Edit Also editing files in the working directory and running project commands such as tests and builds. Pushing and publishing are not included.
Full access Everything, without asking. Use it only in directories you trust.

In edit mode, tests and scripts run code the agents can change. Codex’s sandbox keeps it off the network; Claude Code’s, and Harness Relay’s own around the open-source agents, ask you about each host (an open agent reaches its model backend without asking), and Muse Code’s before a command reaches the network; Grok’s and Copilot’s commands can still reach the network, and Cursor and Antigravity have no sandbox (a command you allow runs with your rights). On native Windows only Codex , Copilot and Muse Code have a sandbox (Muse Code’s after its own one-time setup, which asks for administrator rights; until then its commands fail). Quick start

  1. Install one agent or more

    • Any of these agents: Claude Code (claude), Codex CLI (codex), Grok CLI (grok), Cursor CLI (cursor-agent), Antigravity CLI (agy), GitHub Copilot CLI (copilot), Muse Code (muse)
    • Or the open-source ones (versions tested): OpenCode (opencode-ai 1.19.5), Goose (block-goose-cli 1.58.1), Cline (cline 3.0.74), OpenHands (openhands 1.16.0), Pi (@earendil-works/pi-coding-agent 1.5.1, Node.js 22.19 or newer), with an API key for OpenAI, Anthropic or xAI, or your own endpoint. Below full access they run in a sandbox that needs Node.js 22.12 or newer, and on Linux also bubblewrap, socat and ripgrep.
    • Git, for edit and parallel modes. Nothing else: the app brings what it runs on

  2. Download and open it

    All installers are on the releases page.

    On macOS, drag Harness Relay to Applications; on Windows, the installer sets it up for your user; on Linux, make the AppImage executable and run it. The installers are not signed yet, so the first time: on macOS, System Settings → Privacy & Security → Open Anyway; on Windows, More info → Run anyway.

  3. Sign in, then get to work

    Harness Relay opens in a window of its own, signed in, and stays in the menu bar (or the system tray) when you close it, so your phone can still reach it. Under Settings & sign-in, check that each agent is signed in, or, for the open-source agents, add an API key or your endpoint under Model backends. Then New chat: choose the working directory and permission, and ask your first question.

  4. Open it on your phone

    Optional. Install Tailscale on the computer and on the phone, then choose Share with your phone (Tailscale)… in Harness Relay's menu. It shares the server with your tailnet and shows the https:// address to open on the phone.

    Sign the phone in with a code from Settings → Signed-in browsers → Sign in another device on the computer. Only devices in your tailnet can reach it, and the server stays on 127.0.0.1. To add it to the home screen: Share → Add to Home Screen in Safari on iPhone, ⋮ → Install app in Chrome on Android. Then turn on Settings → Notifications and sound there, to be told when the team finishes or needs you, even with the phone locked.

Try it in GitHub Codespaces

A Linux machine of your own in GitHub's cloud. It installs the seven agents that are not open source (Claude Code, Codex, Copilot, Grok, Cursor, Antigravity and Muse Code) and starts Harness Relay. Nothing goes on your computer.

  • It runs on your GitHub account. A free personal account includes 120 core-hours a month, about 60 hours of this 2-core machine. It stops after 30 minutes without use; delete it at github.com/codespaces when you are done.
  • You still need an agent signed in. Sign in under Settings & sign-in to the ones you have an account for. Copilot signs in with your GitHub account, if it has Copilot (Copilot Free counts).
  • Some things work differently. The open-source agents are not installed: add them from the codespace's terminal (OpenCode then runs with full access only). There is no folder dialog: type the working directory, such as /workspaces/playground. Sharing a conversation as a link needs a GitHub sign-in once, from the share dialog. The desktop app's menu and Tailscale sharing are not there.
  • Only you can open it. Its address is private to your GitHub account, and the agents' sandboxes work there. An agent with full access can use anything in the codespace, its GitHub token included.
  • It runs the newest release, and is counted once. Once it is made, it tells us so with one empty request, nothing about you.

Where Harness Relay opens

The first start takes about two minutes. Then the terminal at the bottom of the editor prints a sign-in link: ⌘-click it on a Mac, Ctrl-click it elsewhere. If the page asks for a code, type the one printed under the link.
