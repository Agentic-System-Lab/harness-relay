Signing in and finding agents

What you see What to try
An agent shows Not signed in Sign it in on its card under Settings & sign-in, or give it an API key, then click Check again.
An agent says Command not found Install it from its card in Settings, or set its Executable (under its accounts) to the program's full path.
The desktop app does not find an agent that works in your terminal After installing an agent, choose Restart server… in the app's menu, so it reads your setup again. If it is still not found, set the agent's Executable in Settings.
Install on an agent's card fails Open the installer's output on the card to see why (a network that blocks the download, a full disk…). Try again, or install the agent as its maker's page says.
An open-source agent shows Not ready Add an API key or your own endpoint under Settings → Model backends, and check that the agent is installed.
An agent's model list is empty or old Click Check again at the top of Settings. You can always pick Custom… and type a model's name.
Saving an API key fails Your system's keychain is locked, or access was refused. Unlock it (or allow access when asked), then save again.

Signing in step by step is on Connect your agents.

Replies and approvals

What you see What to try
An agent seems stuck Look for a Needs you badge or an approval card: it may be waiting for your answer.
A reply ends in an error box Read it: it is the agent's own error, such as a usage limit, a sign-in or a model that does not exist. Fix that, then press Continue or send your message again.
The lead agent always keeps the same team, or uses the General-question panel The team design card says why. Check that the lead agent is signed in (Settings → Lead agent), or choose another one.
An agent seems to have forgotten the conversation When an agent cannot pick up where it was, Harness Relay starts it afresh with the whole conversation. That is expected after you change the working directory or its agent, or raise the permission.
Cursor or Antigravity asks about every command, even tests Expected: neither has a sandbox in Harness Relay, so below full access their commands ask you. Always allow covers the next ones like it.
Antigravity or Copilot stops as soon as you decline something Expected: they end their turn after any refusal, and never see your note. Say what to do instead in your next message.
Connection lost, reconnecting… does not go away Harness Relay's server stopped or is restarting; the page reconnects by itself once it is back. In the desktop app, Start server in its menu starts it again.
Some messages are in the other language Notes and errors are written in the language the app had when they happened; switching the language does not translate them.

Files and working directories

What you see What to try
Sending says another conversation is changing the folder Another chat is writing in the same working directory. Wait until it finishes, stop it, or use read-only or parallel mode.
Applying a result says there is a conflict Your working directory changed since the agents started, so nothing was applied. Send a new message, and the agents start again from the folder as it is now.
Agents in parallel mode cannot run the tests Their copies of the folder lack what git ignores, such as node_modules: ask them to install the project's dependencies first.
A folder is too broad for a working directory It is inside a git repository that holds your whole home folder. Choose a project folder, or run git init in it.
Edit mode is refused for a folder Edit mode is never allowed in your home folder itself, in the settings folders that decide how the agents run, or in a folder that holds Harness Relay. Choose a project folder, or use read-only.

The desktop app

What you see What to try
macOS says Apple could not verify Harness Relay Open System Settings → Privacy & Security and click Open Anyway. The installers are not signed yet, so this happens the first time.
Windows says it protected your PC Click More info, then Run anyway.
The Linux AppImage stops at once Start it with --no-sandbox; Open at login then starts it the same way.
The app says the port is already in use Another Harness Relay (one started from a terminal, say) or another program uses it. Quit that one, then click Try again.
The window or your browser shows the sign-in page Choose Open Harness Relay in the app's menu for its window, or Open in browser for your browser: each signs in again.
The server took too long to start, after an update macOS may be asking whether Harness Relay may use its keys in your keychain. Answer, then choose Start server in the menu.
Open at login does nothing on macOS Allow Harness Relay in System Settings → General → Login Items & Extensions.
An update says Harness Relay cannot update itself, or it failed The dialog says why and links to the release: install it as you did the first time. On a Mac, move the app into Applications first. A failed update changes nothing.

Voice input

What you see What to try
The microphone is not available Allow this page to use the microphone (the site settings beside the address bar), and allow your browser in the system's privacy settings. On a phone, open the https:// address.
Voice input does not install Open Settings → Voice input and read the error and the install log. On macOS, install Homebrew first.
Speech turns into text slowly Choose a smaller model (Small or Base) in Settings → Voice input. The first recording after a while also loads the model.
Chinese comes out in Simplified characters, or the wrong language Set Spoken language to Chinese (Traditional) or English instead of detecting it; a larger model also helps.

On your phone

What you see What to try
The address does not open on the phone Check that Tailscale is on in the phone, signed in to the same tailnet as the computer, and that the computer is awake.
The home-screen icon opens a blank page Turn Tailscale on in the phone, then open the icon again.
Show notifications cannot be turned on on an iPhone or iPad Open Harness Relay from its icon on the home screen, not in Safari, on iOS 16.4 or later. If notifications are blocked, allow them in the phone's Settings → Notifications.
No notifications arrive while the phone is locked Press Send a test notification on the phone; if it fails, turn Show notifications off and on again. Check that the computer is awake and online, and that no Focus mode holds them back.
Share with your phone says it could not read what the computer shares Check that Tailscale runs on the computer and is signed in, then choose Share with your phone again.

Setting it up is on Use it from your phone.

Where your data is

Harness Relay stores everything on your computer. The desktop app keeps your conversations, templates, settings and attached files in a data folder inside its own folder; Open data folder in its menu opens it.

System The app's folder
macOS ~/Library/Application Support/Harness Relay
Windows %APPDATA%\Harness Relay
Linux ~/.config/Harness Relay
  • API keys and passwords are not in that folder: they are in your system's credential store (Keychain on macOS, Credential Manager on Windows, your keyring on Linux).
  • Each agent you sign in to keeps its own session history where it always does, as when you run it yourself; extra accounts and the open-source agents keep theirs in the data folder.
  • To back up, quit the app, then copy its data folder.
  • The server's log opens with Show log in the app's menu: it helps when something goes wrong.

Running Harness Relay from its source, the same files are in the data folder of the project. To uninstall the app and remove your data, see Uninstall.

Report a problem

  1. Click the speech-bubble icon right of Settings & sign-in, at the foot of the sidebar: it opens Report a problem.
  2. Choose Problem, Idea or Other, and write what happened.
  3. Press Send: your mail app opens with the report filled in. Drag screenshots into the mail, then send it.

Nothing leaves your computer until you send the mail, but screenshots you choose to upload (optional: they go up as a secret gist with your GitHub CLI, for the mail to link to). It always includes Harness Relay's version, your system and browser, each agent's version and your language, so the problem is easier to track down; none of your files, folders or accounts go with it. No mail app? Use Send with Gmail, or Copy report and send it from any mail.

If Harness Relay works well for you, the star beside that icon opens a short dialog to star the project on GitHub.
