Install Harness Relay

Harness Relay is a desktop app for macOS, Windows and Linux. It runs in the background on your computer and shows the chat in a window of its own, already signed in. Download it, open it once, and it keeps itself up to date.

Download the app

Pick the installer for your computer. The card for the system you are on is marked.

macOSmacOS 13 or later · Apple Silicon · .dmg Your system WindowsWindows 10 or later, x64 · .exe Your system Windows on ArmWindows 10 or later, Arm64 · .exe Your system Linuxx64 · .AppImage Your system Linux on ArmArm64 (aarch64) · .AppImage Your system

All installers are on the releases page.

  • macOS: for Macs with Apple Silicon, macOS 13 Ventura or later. There is no app for Intel Macs.
  • Windows: Windows 10 or later. Take the Arm64 installer on Windows on Arm, where it runs natively; Windows 11 on Arm runs the x64 one too, Windows 10 on Arm does not. It installs for your user only, without administrator rights.
  • Linux: a Linux with a desktop, on x64 or 64-bit Arm. The app is one AppImage file.

No computer to install it on?

Try it in GitHub Codespaces: a Linux machine of your own in GitHub's cloud, in your browser, with the seven agents that are not open source installed and Harness Relay started. It runs on your GitHub account: a free personal account includes about 60 hours of it a month. Start from the quick start on the home page, which says what to expect first, or read Try it in GitHub Codespaces.

On an Intel Mac, or a server without a desktop, run Harness Relay from its source instead: see the README's quick start.

Open it the first time

The installers are not signed for distribution yet, so your system warns you the first time the app opens. Here is how to get past it on each system:

System Install it, then open it the first time
macOS Open the .dmg and drag Harness Relay to Applications. The first time it opens, macOS says Apple could not verify “Harness Relay”. Open System Settings → Privacy & Security and click Open Anyway next to Harness Relay.
Windows Run the .exe. It installs for your user. The first time it opens, SmartScreen says Windows protected your PC. Click More info, then Run anyway.
Linux Make the AppImage executable (chmod +x, or the file's properties), then run it. On Ubuntu 24.04 and other systems that restrict user namespaces, it may stop at once with a message about the SUID sandbox helper. Start it with --no-sandbox; Open at login then starts it the same way.

Harness Relay then opens the chat in its own window, signed in: there is no code to type. On a Mac, if an agent later works in a folder such as Documents or Desktop, or you use voice input, macOS asks whether Harness Relay may do so. The question names the app because the agents run inside it: choose Allow.

Language, appearance and the tour

  • The app speaks English and 繁體中文. The first time, it follows your browser's language; change it under Settings & sign-in → Language. The app's own menus follow the language its window shows.
  • Its colours follow your system's light or dark mode. To keep one, choose Light or Dark under Settings & sign-in → Appearance; Follow system goes back.
  • A short guided tour points out the main features the first time (← and → to move, Esc to skip). See it again with Replay the tour under Settings & sign-in → Guided tour.

The window and the menu

Closing the window does not stop Harness Relay: it keeps running, with its icon, the three dots, in the menu bar on macOS and in the system tray on Windows and Linux. That way the team can finish its work, and your phone can still reach it. To stop it, choose Quit Harness Relay in that menu (⌘Q on macOS): it stops every agent first. On Windows, a click on the icon opens the chat, and the menu is on the right button.

Menu item What it does
Open Harness Relay Shows the chat's window. Opening the app again from the Dock or the Start menu does the same.
Open in browser Opens the chat in your default browser instead, signed in.
Share with your phone (Tailscale)… Makes Harness Relay reachable from your phone: see Use it from your phone.
Open at login Starts the app when you log in, without opening its window.
Keep this computer awake while running Keeps the computer from going to sleep by itself, so your phone can reach it. A MacBook still sleeps when you close the lid.
Restart server… Starts Harness Relay again, for example after you installed an agent in a terminal. Replies in progress stop.
Update to … Shown when a newer version is out: see Updates.

Some Linux desktops hide tray icons (GNOME without the AppIndicator extension, for one). There, opening the app again shows its window, and the window's menu bar (Alt) has Open in browser and Quit. For the rest of the menu, install the AppIndicator extension.

What else you need

At least one agent

Harness Relay works with the coding agents you have: any of the seven you sign in to (Claude Code, Codex, Grok, Cursor, Antigravity, Copilot and Muse Code) or the five open-source ones (OpenCode, Goose, Cline, OpenHands and Pi), in any mix. One is enough to start. Connect your agents shows how to sign each one in.

You don't have to install them yourself. When Harness Relay does not find an agent, its card under Settings & sign-in shows a button to install it. One click installs it in a folder of its own, for Harness Relay alone, shows the installer's output as it goes, and checks that it runs; Remove takes it away again. Claude Code, Codex and Copilot install this way even without Node.js on your computer. If you install an agent yourself in a terminal while the app is open, choose Restart server… in its menu so that it finds the agent.

Git, for edit and parallel modes

When agents may change files, Harness Relay uses Git to record what each reply changed and to give each agent a copy of its own in parallel mode. Install it if you don't have it. You don't need to know Git: Harness Relay never commits to your branch.

What the sandboxes need

Unless you give a chat full access, the commands most agents run go in your system's sandbox, which lets them write only in the chat's folders. When the sandboxes are missing something on your computer, New chat first shows a dialog that lists it. Choose Install (strongly recommended): on Linux it asks for your administrator password (or gives you the command to run in a terminal), then installs the packages; Not now closes it. The same list, with Install, is always under Settings & sign-in → Sandboxes. On Windows there is nothing to install: only Codex and Copilot have a sandbox there, and they need nothing.

Without what they need, the agents' commands fail rather than run outside the sandbox. The open-source agents run in Harness Relay's own sandbox; on native Windows they run with full access only. See Permissions and approvals.

Updates

The app checks GitHub for a newer version shortly after it starts and every hour after that. When there is one:

  1. The menu shows Update to and the new version, and the chat offers it once in a dialog and in the Version card at the top of Settings & sign-in. What’s changed lists every change since your version; Later stops it offering that version.
  2. Choose Update. The app downloads the new version and checks it against the checksum GitHub publishes.
  3. It waits until no chat has agents at work (a chat waiting for your answer does not count), then quits and opens again as the new version. Switch to the new version now… in the menu switches at once, stopping the replies.

On a Mac, keep the app in Applications: one run from the .dmg cannot replace itself. If macOS keeps it from doing so, the new version's .dmg opens: drag Harness Relay into Applications again.

A version is the date it came out, in Taiwan's time zone, such as 2026-11-10; a fix released the same day adds a number, 2026-11-10.1. A version ending in -rc is a release candidate, made to be tried before a release: the website offers releases only, and an app that is a release candidate also updates to the next release candidate.

Uninstall

  1. Turn Open at login off and, if you shared Harness Relay with your phone, stop sharing it: in a terminal, run tailscale serve --https=443 off (or the port the phone address ends in, such as 8443). Then quit the app.
  2. Remove the app: drag it from Applications to the Trash on macOS; on Windows, Settings → Apps → Installed apps (Apps & features on Windows 10) → Harness Relay → Uninstall; on Linux, delete the AppImage.
  3. To remove your conversations and settings too, delete the app's folder: ~/Library/Application Support/Harness Relay on macOS (and ~/Library/Logs/Harness Relay), %APPDATA%\Harness Relay on Windows, ~/.config/Harness Relay on Linux. Your API keys are in the system's credential store under harness-relay-desktop (Keychain Access on macOS, Credential Manager on Windows, your keyring on Linux): delete those entries.

The user guide covers the rest: every menu item, how updates are checked, what differs from running from source, and the data the app keeps.
