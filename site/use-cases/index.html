Twelve examples to get you started

Tell Harness Relay what you need, and the lead agent puts together a team from the coding agents you already have. These twelve examples are just a starting point. Bring your curiosity and a task of your own, and see what else your team can do.

Each example lists the agents involved and includes a recording of the real run. The video speeds up while the agents work.

Software engineers Product managers Marketers Accountants Business owners Account managers Researchers Teachers Lawyers On-call engineers Designers Localization teams

For software engineers

Fix a bug three ways, keep the best one

A test fails, and one fix is a guess. Ask for three: in parallel mode each agent works in a git worktree of its own, so their fixes never touch each other or your files. Each reply lists the files it changed; you read the diffs and apply the one you want to your working directory, uncommitted, to check with your usual tools.

Turn customer interviews into a spec

Attach the interviews and ask for a PRD, as a relay: one agent pulls out each pain point in the customer’s own words, the next writes the spec, the last challenges its assumptions. What only you can decide, they ask you first: here, which customers to build for. Your answer goes into the PRD, saved in your working directory.

Read the competition, then write the launch

To try another voice, branch the conversation: the first one stays as it was.

For accountants

Close the month: three reconciliations, compared

One reconciliation can miss a line. Ask three agents to reconcile the same files on their own: in parallel mode none sees the others’ work until it has done its own, read-only all along. Each lists the differences and the entries that fix them; then the lead agent reviews the three: where they agree, where they differ, and what you should confirm yourself.

For business owners

Chase overdue invoices until they are settled

Give an automation a goal and it follows the task across days. Every weekday morning the agents read your mail with Harness Relay’s own tools, check who paid and write the reminders; each mail waits in the outbox until you press Send. Each run starts from what the last one found, and once the goal is reached the automation stops.

Recorded with stand-in mail servers on the same computer, holding made-up messages; the second run is started by hand, as the next morning’s would start by itself.

Recorded with stand-in mail and calendar servers on the same computer, holding made-up messages and events; the call is added to the calendar during the recording, instead of waiting for the clock to bring it near.

For teachers

Write a quiz, and try it on a student first

Ask for a quiz, and for a team that tests it: in relay mode one agent writes the questions and the answer key, the next takes the quiz as a student would, without the key, and the last marks it. Any question the student could misread goes back to be rewritten (here the student scored full marks, and none did). The quiz and its key are saved in your working directory; download the folder as one ZIP file.

For lawyers

Redline a contract, on your own model server

A confidential contract need not leave your network. Point Claude Code, Codex and Grok at a model server of your own (here Qwen3.8 27B, served by vLLM) and the lead agent too, then ask for a redline as a relay: one agent edits each clause that departs from your playbook, the next checks every edit, the last writes the memo for the vendor. Harness Relay keeps the folder in git, so a reply’s diff is the redline, clause by clause.

Recorded with every agent, the lead agent included, on Qwen3.8 27B (NVFP4), served by vLLM on a DGX Spark on the same network; the contract and the playbook are made up.

For localization teams

Translate the moment the English changes

Let a file start the team. When locales/en.json changes, an automation hands the change to agents from three makers, in relay: Antigravity translates into Traditional Chinese and Japanese, Copilot translates them back without seeing the English, and Claude Code compares them, checks every placeholder and fixes or sends back what drifted. What the team writes never starts the automation again.

Recorded with a made-up app’s strings; the recording changes en.json, as you would in your editor.

  • Antigravity
  • Copilot
  • Claude Code
  • Relay
  • Edit

What you ask

When locales/en.json changes: translate each string that was added or changed into locales/zh-TW.json and locales/ja.json, following GLOSSARY.md, and keep every {placeholder}, plural and tag as it is. As a relay: Antigravity translates; Copilot reads only the two translations, never en.json, and translates them back into English; Claude Code compares the back-translations with en.json, checks the placeholders and the button lengths, and sends any string whose meaning drifted back to Antigravity to fix.

What it shows

  • A file that changes. The automation waits for a pattern in the working directory; a file counts once it has been still for 30 seconds, and what the team writes there never counts. When it runs
  • Any of the agents you have. Antigravity and Copilot work with Claude Code here, each signed in from Settings; the lead agent builds the team only from the agents you have ready. Sign in to an agent
  • Add to the discussion while they reply. A message sent mid-reply waits above the box and reaches the next agent before its turn; until then you can edit or withdraw it. While the team works
