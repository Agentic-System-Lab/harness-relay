Five tasks to hand the team

Harness Relay is a task assistant: say what you need, the lead agent designs a team for it, and the coding agents you already have do it together on your computer. Each task below is a real run of the agents listed with it, recorded as it happened and sped up while they work.

Fix a bug three ways Research a choice Write release notes Analyze a spreadsheet A morning briefing

Fix a bug three ways, keep the best one

A test fails, and one fix is a guess. Ask for three: in parallel mode each agent works in a git worktree of its own, so their fixes never touch each other or your files. Each reply lists the files it changed; you read the diffs and apply the one you want to your working directory, uncommitted, to check with your usual tools.

What you ask

The tests fail: splitBill gains or loses a cent when the bill doesn’t divide evenly. Have Claude Code, Codex and Grok each fix it in parallel, each in the git worktree Harness Relay gives it, and run npm test there.

What it shows

  • Parallel mode. Everyone answers at once, independently, each in a worktree of its own. Conversation rules
  • Edit permission. Agents may change files in the working directory and run its tests; anything more asks you first. Approvals
  • Diffs and Apply. A reply that changed files lists them, with the diff; Apply copies one result into your working directory and commits nothing. Reviewing and applying changes

Research a choice, with sources

Not every task is code. Ask a question that needs looking up, and the agents search the web and read the docs themselves, then answer each other’s points in a roundtable, read-only all along. You get one recommendation with the links they read, and the lead agent’s review marks where they disagree and what to check yourself.

What you ask

Read NOTES.md. Should we replace Moment.js with date-fns, Day.js or Luxon? Have Claude Code, Codex and Grok look up each one’s docs and npm page, compare time-zone support, size and upkeep, debate it, and give us one pick with links to the sources.

What it shows

  • Roundtable. They speak in turn, each reading what the others said before it. Conversation rules
  • Read-only. They read and search the web, and change nothing. Conversation rules
  • Lead review. Once the team has answered, the lead agent marks risks, disagreements and claims to check right in the replies, and suggests next steps. Lead review

Write release notes as a relay

Writing goes better in passes. In relay mode one agent speaks at a time and hands over with an @mention: here the first drafts the release notes from the commits since the last tag, the next rewrites them for users, the last checks every line against the commits. The file is in your working directory, and Files shows it rendered.

What you ask

Write the release notes for 1.4.0 in RELEASE_NOTES.md, for our users, from the commits since v1.3.0. Pass it along as a relay: Claude Code drafts, Codex edits it into plain words, Grok checks every line against the commits.

What it shows

  • Relay mode. One at a time; whoever is @mentioned goes next, and with nobody mentioned it comes back to you. Conversation rules

  • Files. Browse the working directory and preview Markdown, code and images, or download a file. Browsing files

Turn a spreadsheet into answers and a chart

Attach an export and ask what changed. Rather than guess from a glance, the agents count with scripts of their own and check each other’s numbers, then rank what to fix first. The chart they save in your working directory shows right in the reply, ready for the weekly update.

A morning briefing from your mail and calendar

Hand the team a job that repeats. An automation sends its message every weekday at 08:30; the agents read your mail and calendar with Harness Relay’s own tools, tell you what needs you today and write the replies. Nothing reaches anyone in their turn: each mail waits in the outbox, field by field, until you press Send.

Recorded with stand-in mail and calendar servers on the same computer, holding made-up messages and events.

What you ask

Every weekday morning, with Harness Relay’s mail and calendar tools: read the mail that came in since yesterday and today’s calendar, and tell me what needs me today. Answer each mail that needs a reply with mail_send: it sends nothing by itself, each reply waits in my outbox until I press Send (an unattended run cannot save drafts). For each meeting request, propose a free time in the reply. Claude Code reads the mail, Codex checks the calendar.

What it shows

  • Automations. At set times, when you run one now, when something happens (a new mail, an event about to begin, a pull request or a failed CI run on GitHub, a file that appears or changes), or when a program calls its webhook; while nobody watches, anything beyond the permission is refused. Automations
  • Mail and calendar. Harness Relay’s own tools, for your accounts with an app password; Microsoft 365, Outlook.com and Google calendars and mail sign in in the browser instead. The passwords and tokens stay in your OS credential store. Harness Relay’s tools
  • The outbox. A mail or an invitation never goes out in the agent’s turn: it waits as a card until you press Send, or Discard. Approvals

Hand it a task of your own

Any of the twelve agents, and one kind is enough for a team. The desktop app runs on macOS, Windows and Linux; or try it in a GitHub codespace, with nothing to install.
