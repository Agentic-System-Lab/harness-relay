Claude Code、Codex 和 Grok，同一個群組聊天

替每個 agent 安排角色、決定輪流發言的方式，讓你電腦上真正的 CLI 一起處理你的程式碼或任何問題，並且互相回應。 

$ git clone https://github.com/Agentic-System-Lab/harness-relay
$ cd harness-relay
$ npm install
$ npm run build
$ npm start
在 GitHub 查看 需求與快速開始

看一次完整流程

先新增群組，再在這個 repository 上使用自動組隊，從描述需求、得到答案、查看討論到的程式碼到搜尋。agent 工作的片段已加速。

是你自己的 CLI，不是仿製品

Harness Relay 不會自己呼叫任何模型 API。它啟動你已經安裝的 claude、codex 和 grok，保有它們各自的工具、session 與登入狀態，把每個 agent 還沒看過的訊息交給它，再把所有內容串流到同一個聊天室。

Claude Code
claude，雙向使用 stream-json；它的權限請求會變成聊天裡的核准卡片。
Codex
codex app-server：thread、turn 與核准請求。
Grok
透過 grok agent stdio 使用 Agent Client Protocol（ACP）。

不必三個都有：任何組合都能用，各自在設定頁登入即可。

決定他們怎麼輪流發言

每個對話都有自己的規則：誰發言、什麼順序、何時結束。用 @名稱 指定成員，就只有被指定的人回覆。

圓桌

agent 依序發言，每位都看得到前面的人說了什麼。可設定 1 到 5 輪；某一輪所有人都回覆 [PASS] 時提前結束。

適合討論、審查，以及把答案修得更好。

平行

每一輪大家同時、各自獨立回答；下一輪才看得到彼此的答案。可編輯時每個 agent 在自己的 git worktree 工作，再由你選擇要套用哪一份結果。

適合比較不同做法、取得獨立的意見。

接力

一次一位發言。agent 用 @名稱 把發言權交給隊友；沒有 @ 任何人時，就交還給你。你可以設定最多交棒幾次。

適合流水線：規劃、實作、審查。

自己設計團隊，或交給首席 agent

自己設計。替每個 agent 決定定位（架構師、實作者、審查者、魔鬼代言人），選擇模型與推理強度，並安排發言順序。最多八位成員，同一個 CLI 也可以有好幾位；對話中也能隨時修改角色。

或使用自動組隊。描述你的需求，首席 agent 會讀它與所有範本的完整內容，再決定直接套用範本、依範本調整，或從頭設計新團隊，並說明原因。你確認後才有人開始回答，它設計的團隊也能存成範本。

每個對話都有

  • 附加檔案直接貼上截圖或拖曳檔案，每個 agent 都拿得到，圖片也會直接交給三種 CLI 看。
  • 語音輸入，在你的電腦上whisper.cpp 在本機把語音轉成文字；不需要就不會安裝。
  • 看見思考與動作推理過程、計畫與每個工具的輸出即時串流；Mermaid 程式碼區塊會畫成圖表。
  • 複製、編輯與重試把一則訊息或整段對話複製成 Markdown；編輯自己的訊息或重試某則回覆，團隊就從那裡重新回答。
  • 排程傳訊息在設定的時間把訊息傳給團隊，就在同一個對話裡：一次、每天、每週選定的星期幾，或每隔幾小時。排程執行時可能沒人看著，所以預設會自動拒絕權限範圍以外的動作（設為本對話都允許的除外）。Harness Relay 關閉期間錯過的時間會略過，也可以選擇在開啟後補送一次。
  • 狀態一目了然側邊欄標示需要你處理、正在回覆或有新回覆的對話；切換到別的對話時，原本的對話會繼續執行。
  • 在 app 裡登入每個 CLI 都能用裝置碼、瀏覽器或貼上授權碼登入，也能設定 API key、執行檔路徑與預設模型，並查看各 CLI 自己載入的 skill、MCP 工具、內建工具、hook、subagent、plugin、指示與記憶，也能讓 Harness Relay 執行時整類或逐項不載入。
  • 聊天室裡的圖片與影片agent 存在工作目錄裡的圖片與影片，會直接顯示在對話中。
  • 瀏覽工作目錄上方的「檔案」列出工作目錄或某位成員的 worktree，並預覽附行號的程式碼、Markdown、圖片與影片。
  • 三種 CLI 共用的工具庫MCP 伺服器、skill 與記憶設定一次，Claude Code、Codex 和 Grok 都能用，而且加在各 CLI 自己的設定之外；每一項可以只給某幾種 CLI 或特定成員。
  • 在 AgentsView 中看每個 session可以讓各 CLI 使用自己的資料夾，並在 AgentsView 中把每個對話看成一個 thread，底下是每位成員自己的 session（工具呼叫、token 與成本）。
  • English 與繁體中文介面跟著瀏覽器的語言，第一次開啟時有使用導覽。

完全在你的電腦上執行

沒有任何雲端服務。伺服器只在你的電腦上監聽，agent 的回覆也無法讓瀏覽器載入遠端內容。

  • 只綁定 127.0.0.1，並拒絕跨站請求。
  • 每個改檔的回合都有 git 快照；平行模式的 agent 在各自的 worktree 工作。
  • API key 與 MCP 伺服器的 token 存在作業系統的憑證儲存區：macOS 鑰匙圈、Windows 認證管理員或 Secret Service。
  • 所有對話都存在一個 SQLite 檔案裡。

快速開始

  1. 安裝需要的工具

    • Node.js 22.13 以上
    • 任一 CLI：Claude Code（claude）、 Codex CLI（codex）、Grok CLI（grok）

  2. 下載並啟動

    $ git clone https://github.com/Agentic-System-Lab/harness-relay
$ cd harness-relay
$ npm install
$ npm run build
$ npm start

  3. 登入，然後開始聊天

    打開 http://127.0.0.1:8787，在「設定與登入」確認每個 agent 都已登入，再按「新對話」：選擇自動組隊、自行設計，或挑一個範本。

  4. 用手機打開

    選用。在電腦和手機都裝好 Tailscale。先停止伺服器，把它分享到你的 tailnet，再用 tailscale serve 印出的名稱重新啟動： 

    $ tailscale serve --bg 8787
$ RELAY_ALLOWED_HOSTS=my-computer.tail1234.ts.net npm start

    用手機打開那個 https:// 網址。只有 tailnet 裡的裝置連得到，伺服器仍然只綁定 127.0.0.1。加到主畫面：iPhone 用 Safari 點分享 → 加入主畫面，Android 用 Chrome 點 ⋮ → 安裝應用程式。

    完整步驟，以及讓它一直執行與疑難排解

要開發 Harness Relay 本身？改用 npm run dev：改程式時伺服器會自動重啟、介面會自動重新載入，網址是 http://localhost:5173。
