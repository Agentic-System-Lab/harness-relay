Claude Code、Codex 和 Grok，同一個群組聊天

替每個 agent 安排角色、決定輪流發言的方式，讓你電腦上真正的 CLI 一起處理你的程式碼或任何問題，並且互相回應。

看一次完整流程

先新增群組，再在這個 repository 上問兩個問題，每個問題都由首席 agent 組隊，從提問、得到答案、查看討論到的程式碼到搜尋。agent 工作的片段已加速。

是你自己的 CLI，不是仿製品

Harness Relay 不會自己呼叫任何模型 API。它啟動你已經安裝的 claude、codex 和 grok，保有它們各自的工具、session 與登入狀態，把每個 agent 還沒看過的訊息交給它，再把所有內容串流到同一個聊天室。

Claude Code
claude，雙向使用 stream-json；它的權限請求會變成聊天裡的核准卡片。
Codex
codex app-server：thread、turn 與核准請求。
Grok
透過 grok agent stdio 使用 Agent Client Protocol（ACP）。

不必三個都有：任何組合都能用，各自在設定頁登入即可。

每個對話都有自己的規則：誰發言、什麼順序、何時結束。用 @名稱 指定成員，就只有被指定的人回覆。

圓桌

agent 依序發言，每位都看得到前面的人說了什麼。可設定 1 到 5 輪；某一輪所有人都回覆 [PASS] 時提前結束。

適合討論、審查，以及把答案修得更好。

平行

每一輪大家同時、各自獨立回答；下一輪才看得到彼此的答案。可編輯時每個 agent 在自己的 git worktree 工作，再由你選擇要套用哪一份結果。

適合比較不同做法、取得獨立的意見。

接力

一次一位發言。agent 用 @名稱 把發言權交給隊友；沒有 @ 任何人時，就交還給你。你可以設定最多交棒幾次。

適合流水線：規劃、實作、審查。

每個問題都有適合的團隊

首席 agent 負責挑。每個新問題，它都會讀問題、先前的對話、目前的團隊與所有範本的完整內容，再決定沿用團隊、直接套用範本、依範本調整，或從頭設計新團隊，並說明原因。你確認後團隊才開始回答，也可以設定為直接採用。

範本由你設計。替每個 agent 決定定位（架構師、實作者、審查者、魔鬼代言人），選擇模型與推理強度，並安排發言順序。最多八位成員，同一個 CLI 也可以有好幾位；首席 agent 設計的團隊也能一鍵存成範本。

每個對話都有

  • 附加檔案直接貼上截圖或拖曳檔案，每個 agent 都拿得到，圖片也會直接交給三種 CLI 看。
  • 語音輸入，在你的電腦上whisper.cpp 在本機把語音轉成文字；不需要就不會安裝。
  • 看見思考與動作推理過程、計畫與每個工具的輸出即時串流；Mermaid 程式碼區塊會畫成圖表。
  • 複製、編輯與重試把一則訊息或整段對話複製成 Markdown；編輯自己的訊息或重試某則回覆，團隊就從那裡重新回答。
  • 分支對話回覆下方的「分支對話」會把到這則回覆為止的對話複製成新對話，讓你試另一個方向，原本的對話維持不變。
  • 把對話分享成連結把整段對話，或到某則回覆為止的內容，分享成和聊天室一樣的頁面，不含工具呼叫和思考過程。它會用你的 GitHub CLI 上傳成 secret gist，在 gistpreview.github.io 打開；設定頁列出所有連結，可以移除不要的。
  • 排程傳訊息在設定的時間把訊息傳給團隊，在同一個對話裡或每次開新對話：一次、每天、每週選定的星期幾，或每隔幾小時。也可以從「新排程」開始，由首席 agent 挑選團隊。排程執行時可能沒人看著，所以預設會自動拒絕權限範圍以外的動作（設為本對話都允許的除外）。Harness Relay 關閉期間錯過的時間會略過，也可以選擇在開啟後補送一次。
  • 狀態一目了然側邊欄標示需要你處理、正在回覆或有新回覆的對話；切換到別的對話時，原本的對話會繼續執行。
  • 在 app 裡登入每個 CLI 都能用裝置碼、瀏覽器或貼上授權碼登入，也能設定 API key、執行檔路徑與預設模型，並查看各 CLI 自己載入的 skill、MCP 工具、內建工具、hook、subagent、plugin、指示與記憶，也能讓 Harness Relay 執行時整類或逐項不載入。
  • 聊天室裡的圖片與影片agent 存在工作目錄裡的圖片與影片，會直接顯示在對話中。
  • 瀏覽工作目錄上方的「檔案」列出工作目錄或某位成員的 worktree，並預覽附行號的程式碼、Markdown、圖片與影片。任何檔案都能下載，資料夾也能下載成 ZIP 檔。
  • 三種 CLI 共用的工具庫MCP 伺服器、skill 與記憶設定一次，Claude Code、Codex 和 Grok 都能用，而且加在各 CLI 自己的設定之外；每一項可以只給某幾種 CLI 或特定成員。
  • 在 AgentsView 中看每個 session可以讓各 CLI 使用自己的資料夾，並在 AgentsView 中把每個對話看成一個 thread，底下是每位成員自己的 session（工具呼叫、token 與成本）。
  • English 與繁體中文介面跟著瀏覽器的語言，第一次開啟時有使用導覽。

完全在你的電腦上執行

沒有任何雲端服務。伺服器只在你的電腦上監聽，agent 的回覆也無法讓瀏覽器載入遠端內容。

  • 只綁定 127.0.0.1，只接受你登入過的瀏覽器，並拒絕跨站請求。
  • 完全存取以外，每個 agent 的指令都在它那個 CLI 自己的作業系統沙箱中執行：只能寫入工作目錄，讀不到你瀏覽器的資料夾與 Harness Relay 的資料。
  • 每個改檔的回合都有 git 快照；平行模式的 agent 在各自的 worktree 工作。
  • API key 與 MCP 伺服器的 token 存在作業系統的憑證儲存區：macOS 鑰匙圈、Windows 認證管理員或 Secret Service。
  • 所有對話都存在一個 SQLite 檔案裡；只有在你把對話分享成連結時，Harness Relay 才會把它發布出去。

快速開始

  1. 安裝需要的工具

    • 任一 CLI：Claude Code（claude）、 Codex CLI（codex）、Grok CLI（grok）
    • Git，編輯與平行模式需要。其他都不用裝：app 自己帶著執行所需的一切

  2. 下載並打開

    macOSmacOS 13 以上 · Apple Silicon · .dmg 你的系統 WindowsWindows 10 以上，x64 · .exe 你的系統 Windows（Arm）Windows 10 以上，Arm64 · .exe 你的系統 Linuxx64 · .AppImage 你的系統 Linux（Arm）Arm64（aarch64）· .AppImage 你的系統

    所有安裝檔都在 Releases 頁面。

    macOS 上把 Harness Relay 拖到「應用程式」；Windows 上安裝程式會替你的帳號裝好；Linux 上把 AppImage 加上執行權限後執行。安裝檔還沒有簽章，所以第一次開啟時：macOS 請到系統設定 → 隱私權與安全性 → 強制打開；Windows 請按其他資訊 → 仍要執行。

  3. 登入，然後開始聊天

    Harness Relay 會在它自己的視窗裡打開已登入的對話；關掉視窗後，它會繼續待在選單列（或系統匣），手機照樣連得到。在「設定與登入」確認每個 agent 都已登入，再按「新對話」：選好工作目錄與權限，直接提出第一個問題。

  4. 用手機打開

    選用。在電腦和手機都裝好 Tailscale，再從 Harness Relay 的選單選分享到手機（Tailscale）…。它會把伺服器分享到你的 tailnet，並顯示手機要打開的 https:// 網址。

    用電腦上「設定 → 已登入的瀏覽器 → 讓另一個裝置登入」產生的代碼讓手機登入。只有 tailnet 裡的裝置連得到，伺服器仍然只綁定 127.0.0.1。加到主畫面：iPhone 用 Safari 點分享 → 加入主畫面，Android 用 Chrome 點 ⋮ → 安裝應用程式。

    完整步驟，以及讓它一直執行與疑難排解

要在沒有桌面環境的伺服器上執行，或要開發 Harness Relay 本身？請用 Node.js 22.13 以上從原始碼執行：npm start，修改程式時則用 npm run dev。
