交給團隊的十種工作

Harness Relay 是任務助理：你說要做什麼，首席 agent 就為它設計團隊，你手上的 coding agent 在你的電腦上一起完成，不管你做的是哪一行。以下每件事都是實際執行的錄影，執行的 agent 列在各段裡，agent 工作的段落加速播放。

軟體工程師 產品經理 行銷 會計 經營者 研究人員 老師 法務 值班工程師 設計師

給軟體工程師

一個 bug 三種修法，留下最好的

測試沒過，只有一種修法等於用猜的。那就要三種：在平行模式下，每位 agent 都在自己的 git worktree 裡工作，修法不會互相干擾，也不會動到你的檔案。每則回覆都列出改了哪些檔案；你看完差異，把想要的那個套用到工作目錄，不會自動 commit，再用你慣用的工具檢查。

給經營者

追逾期帳款，追到收齊為止

給自動任務一個目標，它就會跨天追蹤這件事。每個工作日早上，agent 用 Harness Relay 自己的工具讀你的信，查誰付了款、寫好提醒信；每封信都在待送出匣等你按「送出」。每次執行都接著上次的發現，目標一達成，自動任務就停下來。

錄影時用的是同一台電腦上的替身郵件伺服器，信件都是虛構的；第二次執行是手動啟動的，隔天早上那次則會自己開始。

給法務

用自己的模型伺服器修訂合約

機密合約不必離開你的網路。讓 Claude Code、Codex 和 Grok 都改用你自己的模型伺服器（這裡是 vLLM 上的 Qwen3.8 27B），首席 agent 也一樣，再請他們用接力的方式修訂：一位改掉每一條偏離審閱準則的條款，下一位檢查每處修改，最後一位寫給廠商的說明。Harness Relay 用 git 管理這個資料夾，所以回覆的差異就是逐條的修訂紀錄。

錄影時每位 agent，連首席 agent 在內，都跑在同一個網路裡一台 DGX Spark 上、由 vLLM 提供的 Qwen3.8 27B（NVFP4）；合約和審閱準則都是虛構的。
