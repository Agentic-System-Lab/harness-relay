在手機上使用

Harness Relay 在你的電腦上執行，你的 agent、專案與登入都在那裡。透過 Tailscale（只連接你自己裝置的私人網路），你可以在任何地方用手機、平板或另一台電腦打開同樣的對話，不必把 Harness Relay 開放到 Wi-Fi 或網際網路。

分享到手機

需要準備：

  • 執行 Harness Relay 的電腦與手機都裝好 Tailscale（手機用 Tailscale App），並登入同一個 tailnet。
  • 在 Tailscale 管理後台的 DNS 頁開啟 MagicDNS 與 HTTPS 憑證。

接著用桌面 app：

  1. 打開 Harness Relay 的選單（macOS 在選單列，Windows 與 Linux 在系統匣，圖示是三個圓點），選分享到手機（Tailscale）…。
  2. 第一次分享時，如果你的 tailnet 還不允許分享或 HTTPS，app 會在瀏覽器打開 Tailscale 的對應頁面。在那裡允許之後，再選一次分享到手機。
  3. app 會顯示手機要打開的網址，例如 https://my-computer.tail1234.ts.net。之後在同一個選單選複製手機網址就能複製它。

在 Mac 上，裝好 Tailscale App 就夠了。在 Linux 上，如果 Tailscale 不允許你的帳號修改設定，app 會顯示要先執行一次的指令。這台電腦原本分享到 tailnet 的其他服務都不受影響。

讓手機登入

在手機上開啟 Tailscale，打開那個網址。第一次會顯示登入頁：在電腦上打開設定 → 已登入的瀏覽器 → 讓另一個裝置登入，把它顯示的代碼輸入手機（或在手機上打開它的連結）。之後對話、設定與語音輸入都和在電腦上一樣，版面會配合小螢幕調整。

  • 工作目錄是那台電腦上的資料夾，不是手機上的。
  • agent 做的檔案（PDF、簡報、試算表）：點回覆裡的連結，或在檔案裡按下載，檔案就會存到手機上。
  • 對話會繼續跑：手機鎖定或關掉頁面時，對話仍在電腦上進行。回來後頁面會補上進度。
  • 用手機登入 agent：選會顯示連結或代碼的方式。Codex 的 ChatGPT 瀏覽器登入會在電腦上開瀏覽器，請改用 ChatGPT 裝置碼。

加到主畫面

把圖示（Harness Relay 的三個圓點）放到主畫面，點一下就會像 App 一樣全螢幕打開對話。手機的 Tailscale 要開著、而且連得到那台電腦，圖示才能用。

iPhone 與 iPad

  1. 用 Safari 打開網址。
  2. 點分享（看不到的話，先點有三個點的按鈕），再點加入主畫面。
  3. 如果有以網頁 App 開啟，保持開啟，然後點加入。

Android

  1. 用 Chrome 打開網址。
  2. 點右上角的選單按鈕（三個點），再點安裝應用程式（有些版本叫加到主畫面或安裝並建立捷徑）。
  3. 點安裝。

手機上的通知

想把手機放在口袋裡也知道團隊回覆完或需要你：在手機上打開設定與登入 → 通知與提示音，開啟顯示系統通知。iPhone 與 iPad 要在主畫面的圖示裡設定（iOS 16.4 以上）：Safari 自己的分頁收不到通知。按傳送測試通知可以試試看。

之後即使手機鎖定、頁面關掉，手機也收得到通知，只要電腦在執行 Harness Relay 而且連得上網路。收通知不需要手機開著 Tailscale，打開對話才需要。

通知會顯示回覆的開頭，或 agent 要你核准的指令，所以可能出現在鎖定畫面上。若要保密，可以在手機的通知設定裡選擇在鎖定畫面隱藏預覽。

讓它一直連得到

只有電腦醒著、Harness Relay 在執行時，手機才連得到它。在 app 的選單開啟登入時自動啟動，重新開機後它就會再啟動；再開啟執行時不讓電腦睡著。MacBook 闔上螢幕時仍會睡著。

不用桌面 app 時

如果你從原始碼執行 Harness Relay，或在沒有桌面的伺服器上執行，就要自己用 tailscale serve 分享，再用那個網址的名稱啟動 Harness Relay。 GitHub 上的手機連線說明有這些指令，以及怎麼讓它在 Mac 或 Linux 伺服器上一直執行。

誰連得到它

  • 只有你 tailnet 裡的裝置，而且走 HTTPS。Harness Relay 本身仍只在那台電腦上接收連線（127.0.0.1）；由 Tailscale 把你裝置的請求轉給它。
  • 只有你登入過的瀏覽器能使用它。不再使用的手機，請在設定 → 已登入的瀏覽器登出。如果你的 tailnet 裡還有其他人，請用 Tailscale 的存取控制，只讓你自己的裝置連到那台電腦。
  • 絕不要用 Tailscale Funnel：它會把頁面公開到整個網際網路。
  • 電腦的名稱會被公開：開啟 HTTPS 後，Tailscale 會把完整名稱（例如 my-computer.tail1234.ts.net）記錄在公開的憑證紀錄中。不要用你想保密的電腦名稱。
