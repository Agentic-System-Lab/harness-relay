安裝 Harness Relay

Harness Relay 是 macOS、Windows 與 Linux 上的桌面 app。它在你的電腦背景執行，對話則顯示在它自己的視窗裡，一打開就已登入。下載、打開一次，之後它會自己保持最新版本。

下載 app

選擇適合你電腦的安裝檔。你目前所用系統的那張卡片會標示出來。

macOSmacOS 13 以上 · Apple Silicon · .dmg 你的系統 WindowsWindows 10 以上，x64 · .exe 你的系統 Windows（Arm）Windows 10 以上，Arm64 · .exe 你的系統 Linuxx64 · .AppImage 你的系統 Linux（Arm）Arm64（aarch64）· .AppImage 你的系統

所有安裝檔都在 Releases 頁面。

  • macOS：給 Apple Silicon 的 Mac，macOS 13 Ventura 以上。Intel Mac 沒有 app。
  • Windows：Windows 10 以上。Windows on Arm 請用 Arm64 安裝檔，它在那裡原生執行；Windows 11 on Arm 也能執行 x64 版，Windows 10 on Arm 則不行。它只安裝給你的帳號，不需要系統管理員權限。
  • Linux：有桌面環境的 Linux，x64 或 64 位元 Arm。App 就是一個 AppImage 檔案。

手邊沒有能安裝它的電腦？

可以在 GitHub Codespaces 試用：GitHub 雲端上一台屬於你的 Linux 機器，在瀏覽器裡就能用，已經裝好七個非開源的 agent 並啟動 Harness Relay。它用你的 GitHub 帳號執行：免費的個人帳號每月大約包含 60 小時。請從首頁的快速開始進入，那裡會先說明要注意什麼，或閱讀在 GitHub Codespaces 試用。

在 Intel Mac 或沒有桌面環境的伺服器上，請改從原始碼執行 Harness Relay：見 README 的快速開始。

第一次打開

安裝檔還沒有為發佈簽章，所以第一次打開 app 時，系統會跳出警告。各系統的處理方式如下：

系統 先安裝，再第一次打開
macOS 打開 .dmg，把 Harness Relay 拖到「應用程式」。第一次打開時，macOS 顯示「Apple 無法驗證『Harness Relay』」。打開系統設定 → 隱私權與安全性，在 Harness Relay 旁按強制打開。
Windows 執行 .exe，它會安裝給你的帳號。第一次打開時，SmartScreen 顯示「Windows 已保護您的電腦」。按其他資訊，再按仍要執行。
Linux 把 AppImage 加上執行權限（chmod +x，或在檔案內容裡設定），再執行它。在 Ubuntu 24.04 這類限制 user namespace 的系統上，它可能一啟動就結束，並提到 SUID sandbox helper。請加上 --no-sandbox 啟動；之後登入時自動啟動也會這樣啟動它。

接著 Harness Relay 會在它自己的視窗打開對話，已經登入，不用輸入代碼。在 Mac 上，之後 agent 第一次在「文件」或「桌面」等資料夾工作，或你第一次使用語音輸入時，macOS 會詢問 Harness Relay 能否這樣做。詢問裡寫的是這個 app 的名稱，因為 agent 在它裡面執行：請選允許。

介面語言、外觀與使用導覽

  • 介面提供 English 與繁體中文。第一次會跟著瀏覽器的語言，之後可以在設定與登入 → 介面語言切換。App 自己的選單會跟著它視窗裡的介面語言。
  • 顏色會跟著系統的淺色／深色模式。想固定其中一種，就在設定與登入 → 外觀選淺色或深色；選跟隨系統則改回來。
  • 第一次打開時，會有簡短的使用導覽：九個主題，每個都有插圖與簡短說明，看過的會打勾（← 與 → 切換，Esc 關閉）。下次首頁會問你要不要看剩下的。想再打開，到設定與登入 → 使用導覽按重新觀看導覽。

視窗與選單

關掉視窗不會停止 Harness Relay：它會繼續執行，圖示（三個圓點）留在 macOS 的選單列，或 Windows 與 Linux 的系統匣。這樣團隊可以把工作做完，手機也還連得到。要停止它，就在那個選單選結束 Harness Relay（macOS 上按 ⌘Q）：它會先停止所有 agent。在 Windows 上，點一下圖示會打開對話，按右鍵則會開啟選單。

選單項目 作用
打開 Harness Relay 顯示對話視窗。從 Dock 或「開始」選單再次打開 app 也一樣。
在瀏覽器打開 改用預設瀏覽器打開已登入的對話。
分享到手機（Tailscale）… 讓手機也能使用 Harness Relay：見在手機上使用。
登入時自動啟動 登入電腦時啟動 app，但不打開視窗。
執行時不讓電腦睡著 讓電腦不會自己進入睡眠，手機才連得到。MacBook 闔上蓋子還是會睡眠。
重新啟動伺服器… 重新啟動 Harness Relay，例如在終端機裝好一個 agent 之後。正在進行的回覆會停止。
更新到 … 有新版本時出現：見更新。

有些 Linux 桌面會隱藏系統匣圖示（例如沒有 AppIndicator 擴充套件的 GNOME）。在那裡，再次打開 app 會顯示它的視窗，視窗的選單列（Alt）裡有在瀏覽器打開與結束。要用選單的其他項目，請安裝 AppIndicator 擴充套件。

還需要什麼

至少一個 agent

Harness Relay 使用你手上的 coding agent：七個要登入的（Claude Code、Codex、Grok、Cursor、Antigravity、Copilot 與 Muse Code；Antigravity 改用 Gemini API key），或五個開源的（OpenCode、Goose、Cline、OpenHands 與 Pi），任意組合都可以。有一個就能開始。怎麼登入各個 agent，見連接你的 agent。

不必自己安裝。Harness Relay 找不到某個 agent 時，它在設定與登入的卡片會出現安裝按鈕。按一下就會把它裝進專屬的資料夾、只給 Harness Relay 用，一邊安裝一邊顯示安裝程式的輸出，並確認它能執行；按移除就會再拿掉。Claude Code、Codex 與 Copilot 即使電腦上沒有 Node.js 也能這樣安裝。如果你在 app 開著時自己在終端機裝了 agent，請在選單選重新啟動伺服器…，它才找得到。

Git，給可編輯與平行模式用

agent 可以修改檔案時，Harness Relay 用 Git 記錄每則回覆改了什麼，並在平行模式下給每個 agent 一份自己的副本。還沒有的話請安裝。你不需要會用 Git：Harness Relay 絕不會 commit 到你的分支。

沙箱需要的東西

除非你給對話完全存取，大多數 agent 執行的指令都在系統的沙箱裡，只能寫入對話的資料夾。這台電腦缺少沙箱需要的東西時，按新對話會先跳出一個列出缺少項目的對話框。請選安裝（強烈建議）：在 Linux 上它會詢問系統管理員密碼（或給你一行在終端機執行的指令），再安裝套件；按先不要則關掉它。同樣的清單與安裝按鈕，一直都在設定與登入 → 沙箱。在 Windows 上不需要安裝任何東西：那裡只有 Codex 與 Copilot 有沙箱，而且它們什麼都不需要。

缺少需要的東西時，agent 的指令會直接失敗，而不是在沙箱外執行。開源 agent 在 Harness Relay 自己的沙箱裡執行；在原生 Windows 上它們只能以完全存取執行。見權限與核准。

更新

App 啟動後不久，以及之後每小時，會到 GitHub 查有沒有新版本。有新版本時：

  1. 選單會出現更新到加上新版本，對話介面也會跳出一次對話框，並顯示在設定與登入最上方的版本卡片。變更內容會列出你的版本之後的每一項變更；按稍後再說就不再為那個版本跳出。
  2. 選更新。App 會下載新版本，並用 GitHub 公布的檢查碼檢查它。
  3. 它會等到沒有任何對話有 agent 在工作（在等你回答的對話不算），然後結束、以新版本重新打開。選單裡的立即切換到新版…會立刻切換，並中斷正在進行的回覆。

在 Mac 上，請把 app 放在「應用程式」：直接從 .dmg 執行的 app 無法取代自己。如果 macOS 不讓它這樣做，會打開新版本的 .dmg：再把 Harness Relay 拖到「應用程式」即可。

版本就是發佈的日期（台灣時區），例如 2026-11-10；同一天再發佈的修正會加上編號，例如 2026-11-10.1。結尾是 -rc 的是候選版本，在正式版本之前先給大家試用：網站只提供正式版本，候選版本的 app 也會更新到下一個候選版本。

解除安裝

  1. 關掉登入時自動啟動；如果分享過到手機，先停止分享：在終端機執行 tailscale serve --https=443 off（手機網址結尾有連接埠時，例如 8443，就換成那個連接埠）。再結束 app。
  2. 移除 app：macOS 上把它從「應用程式」拖到垃圾桶；Windows 上到設定 → 應用程式 → 已安裝的應用程式（Windows 10 是應用程式與功能）→ Harness Relay → 解除安裝；Linux 上刪除 AppImage。
  3. 要連對話與設定一起移除，刪除 app 的資料夾：macOS 的 ~/Library/Application Support/Harness Relay（還有 ~/Library/Logs/Harness Relay）、Windows 的 %APPDATA%\Harness Relay、Linux 的 ~/.config/Harness Relay。你的 API key 在系統金鑰儲存區的 harness-relay-desktop 名下（macOS 的「鑰匙圈存取」、Windows 的認證管理員，或 Linux 的 keyring）：刪除這些項目。

其他細節都在使用者說明裡：每個選單項目、怎麼檢查更新、和從原始碼執行有什麼不同，以及 app 保存哪些資料。
