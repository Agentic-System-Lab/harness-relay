登入與找不到 agent

你看到的狀況 可以試試
agent 顯示未登入 在設定與登入它的卡片上登入，或給它一把 API key，再按重新檢查狀態。
agent 顯示「找不到指令」 從設定頁它的卡片安裝，或把它的執行檔（在各帳號下方）設成程式的完整路徑。
桌面 app 找不到在終端機裡能用的 agent 安裝 agent 之後，在 app 的選單選重新啟動伺服器…，讓它重新讀取你的設定。還是找不到的話，在設定頁指定那個 agent 的執行檔。
agent 卡片上的安裝失敗 打開卡片上的安裝程式輸出看原因（網路擋住了下載、磁碟滿了…）。再試一次，或照 agent 官網的說明自己安裝。
開源 agent 顯示尚未就緒 在設定 → 模型來源加上 API key 或你自己的端點，並確認這個 agent 已經安裝。
agent 的模型清單是空的或過時 按設定頁上方的重新檢查狀態。也可以隨時選自訂…，自己輸入模型名稱。
儲存 API key 失敗 系統的鑰匙圈被鎖住，或存取被拒絕。解鎖（或在詢問時允許存取）後再儲存一次。

一步一步的登入說明在連接你的 agent。

回覆與核准

你看到的狀況 可以試試
agent 好像卡住了 看看有沒有等你核准標籤或核准卡片：它可能正在等你回應。
回覆最後出現錯誤框 讀一下內容：那是 agent 自己的錯誤，例如用量限制、登入，或模型不存在。處理好之後按繼續，或再送一次訊息。
首席 agent 總是沿用同一個團隊，或改用「一般問題智囊團」 團隊設計卡片上會說明原因。確認首席 agent 已登入（設定 → 首席助理），或改選另一個。
agent 好像忘了之前的對話 agent 無法接著原本的進度時，Harness Relay 會帶著整段對話讓它重新開始。更換工作目錄或它用的 agent，或提高權限之後，這是正常的。
Cursor 或 Antigravity 每個指令都要問，連測試也是 正常現象：兩者在 Harness Relay 裡都沒有沙箱，所以在完全存取以外的權限，它們的指令都會問你。選本對話都允許可以涵蓋之後類似的指令。
一拒絕某件事，Antigravity 或 Copilot 就停了 正常現象：它們在任何拒絕之後都會結束這一輪，也看不到你的說明。請在下一則訊息裡說要它改做什麼。
連線中斷，重新連線中…一直不消失 Harness Relay 的伺服器停了或正在重新啟動；恢復後頁面會自動重新連線。用桌面 app 時，在選單選啟動伺服器就會再啟動它。
有些訊息是另一種語言 說明與錯誤會用當時的介面語言寫成；切換語言不會翻譯它們。

檔案與工作目錄

你看到的狀況 可以試試
送出時說另一個對話「正在修改」這個資料夾 另一個對話正在寫入同一個工作目錄。等它結束、停止它，或改用唯讀或平行模式。
套用結果時說有衝突 agent 開始之後，你的工作目錄有了變動，所以什麼都沒套用。送出一則新訊息，agent 就會從資料夾目前的狀態重新開始。
平行模式的 agent 無法跑測試 它們的資料夾副本沒有 git 忽略的檔案，例如 node_modules：請它們先安裝專案的相依套件。
選工作目錄時說「範圍太大」 這個資料夾位在一個包含整個家目錄的 git repository 裡。請改選專案資料夾，或在專案資料夾裡執行 git init。
某個資料夾不能用可編輯模式 家目錄本身、決定 agent 怎麼執行的設定資料夾，以及含有 Harness Relay 的資料夾，都不允許可編輯模式。請改選專案資料夾，或用唯讀。

桌面 app

你看到的狀況 可以試試
macOS 說無法驗證 Harness Relay 打開系統設定 → 隱私權與安全性，按強制打開。安裝檔還沒有簽章，所以第一次會這樣。
Windows 說它已保護你的電腦 按其他資訊，再按仍要執行。
Linux 的 AppImage 一啟動就結束 加上 --no-sandbox 啟動；之後登入時自動啟動也會用同樣的方式啟動它。
app 說連接埠已經有其他程式在使用 另一個 Harness Relay（例如從終端機啟動的那個）或其他程式佔用了它。結束那一個，再按再試一次。
視窗或瀏覽器顯示登入頁 在 app 的選單選打開 Harness Relay（視窗），或在瀏覽器打開（瀏覽器）：都會重新登入。
更新之後，伺服器太久沒有啟動完成 macOS 可能正在詢問 Harness Relay 能否使用鑰匙圈裡它的金鑰。回答之後，在選單選啟動伺服器。
macOS 上登入時自動啟動沒有作用 在系統設定 → 一般 → 登入項目與延伸功能允許 Harness Relay。
更新說 Harness Relay 無法自己更新，或更新失敗 對話框會說明原因，並附上那個版本的頁面：照第一次的方式安裝。在 Mac 上，請先把 app 移到「應用程式」。更新失敗時不會改變任何東西。

語音輸入

你看到的狀況 可以試試
無法使用麥克風 允許這個網頁使用麥克風（網址列旁的網站設定），並在系統的隱私權設定允許你的瀏覽器。在手機上，請打開 https:// 開頭的網址。
語音輸入裝不起來 打開設定 → 語音輸入，看錯誤與安裝紀錄。macOS 請先安裝 Homebrew。
語音轉文字很慢 在設定 → 語音輸入改用較小的模型（Small 或 Base）。隔一段時間後的第一次錄音也要先載入模型。
辨識出簡體字，或語言不對 把辨識語言從自動偵測改成「中文（繁體）」或 English；較大的模型也會比較準。

在手機上

你看到的狀況 可以試試
手機打不開那個網址 確認手機的 Tailscale 已開啟，並登入跟電腦同一個 tailnet，也確認電腦醒著。
主畫面圖示打開後是空白頁 開啟手機的 Tailscale，再點一次圖示。
在 iPhone 或 iPad 上無法開啟顯示系統通知 從主畫面的圖示打開 Harness Relay，不要在 Safari 裡打開，而且要 iOS 16.4 以上。如果通知被封鎖，請在手機的設定 → 通知允許。
手機鎖定時收不到通知 在手機上按傳送測試通知；失敗的話，把顯示系統通知關掉再打開。確認電腦醒著、連得上網路，也沒有被專注模式擋住。
分享到手機說讀不到這台電腦分享了什麼 確認電腦上的 Tailscale 正在執行並已登入，再選一次分享到手機。

設定方式在在手機上使用。

資料存在哪裡

Harness Relay 把所有東西都存在你的電腦上。桌面 app 把你的對話、範本、設定與附加的檔案，放在它自己資料夾裡的 data 資料夾；在它的選單選打開資料夾就會打開它。

系統 app 的資料夾
macOS ~/Library/Application Support/Harness Relay
Windows %APPDATA%\Harness Relay
Linux ~/.config/Harness Relay
  • API key 與密碼不在那個資料夾裡：它們在系統的金鑰儲存區（macOS 的鑰匙圈、Windows 的認證管理員、Linux 的 keyring）。
  • 需要登入的 agent 照樣把自己的 session 紀錄放在它平常放的地方，就像你自己執行它時一樣；多出來的帳號與開源 agent 則放在 data 資料夾裡。
  • 備份：先結束 app，再複製它的 data 資料夾。
  • 伺服器的記錄檔：在 app 的選單選查看記錄檔就會打開，出問題時很有幫助。

從原始碼執行 Harness Relay 時，同樣的檔案放在專案的 data 資料夾。要解除安裝 app 並刪除資料，請見解除安裝。

回報問題

  1. 點側邊欄底部設定與登入右邊的對話框圖示：它會打開回報問題。
  2. 選問題、建議或其他，寫下發生了什麼事。
  3. 按寄出：你的郵件程式會打開，回報內容都已填好。把截圖拖進信裡，再寄出。

在你寄出那封信之前，除了你選擇上傳的截圖（選用：以 secret gist 透過你的 GitHub CLI 上傳，讓信連過去），什麼都不會離開你的電腦。信裡一律會附上 Harness Relay 的版本、你的系統與瀏覽器、各 agent 的版本與語言，比較容易找出問題；你的檔案、資料夾與帳號都不會附上。沒有郵件程式？用用 Gmail 寄，或按複製內容，用任何郵件寄出。

如果你覺得 Harness Relay 好用，那個圖示旁邊的星星會打開一個小對話框，讓你到 GitHub 給這個專案一顆星星。

每種 agent 自己的訊息，以及從原始碼或在伺服器上執行時的問題，都在 GitHub 上的文件裡：

  • 完整的疑難排解
  • 資料存在哪裡
  • 手機連線的疑難排解
